Incident Response Process

1. Identification
   Detect suspicious activity and determine scope.

2. Containment
   Limit spread of attack.

3. Eradication
   Remove malicious components.

4. Recovery
   Restore normal operations.

5. Lessons Learned
   Document findings and improve defenses.

Recommended Actions:

* Block malicious IPs
* Review logs
* Patch affected systems
* Update detection rules
